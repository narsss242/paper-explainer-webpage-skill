# 静态论文讲解的内容约定

这是可调整的数据结构建议，适合已有JSON生成器；不要求重建用户已有结构。

## 一篇内容中保留的字段

| 信息 | 写法 |
|---|---|
| 论文身份 | 标题、年份、标识符、原文路径或URL，区分作者稿与正式版本 |
| 阅读目标 | 一句话说读完能解释什么，而非泛泛“掌握前沿” |
| 开场 | 一个具体困难，先让读者知道为什么需要方法 |
| 训练与使用 | 训练输入和答案来源；使用时输入、输出、额外条件。数据集论文可改为资源与评估用途 |
| 术语 | `name, en, plain, analogy`；类比不能被当成真实物理机理 |
| 方法模块 | `title, why, explanation, analogy, example, bridge, refs` |
| 辅助图 | 明确节点和边，标题标“辅助示意”，注明省略了什么 |
| 原图 | 本地资源、图号/节号/页码、已查看记录；导读`look, read, meaning, use` |
| 实验 | 指标名称、值、数据与设备条件、这项证据能支持什么、原文位置 |
| 边界 | 作者自述、阅读判断、原文不一致分别标识 |
| 总结与来源 | 几个能复述的要点；原文入口可访问 |

## 模块质量对照

较空的写法：“加入注意力提升特征表达能力。”

可学习的写法：“浅层记录同时含有水迹细边缘与接缝噪声，因此作者让更大范围的线索参与筛选。模块先计算不同记录层的重要程度，再调整各位置的影响。可以把它想成从现场笔记中标出重点，但程序并不知道物理原因，权重是否合理仍要看实验。教学例子是接缝旁一条暗线：仅看局部可能混淆，周围湿痕可提供额外线索。筛选后的记录送到画轮廓的解码器。依据：原论文具体节号和图号。”

只有原文确实这样设计时才使用该例子的内容；不能把例句套到所有注意力模型。

## 数据与数值的检查重点

- 先明确按图像、实例、像素还是视频计数。合成与增强版本不等于独立采集场景。
- 同一原图切片、近邻帧与不同增强版本是否跨训练/测试，属于应核对的事项；未经证实不指控数据泄漏。
- 论文报告mIoU时保留名称；若平均方式不清晰则说明，不自行换成单类IoU。
- 教学数字独立标注。例如人工60格、预测60格、重合40格，IoU为50%；不能写成原文实验。
- 参数量和FPS、训练时长和推理时长、单块推理与整幅流程耗时分别说明。
- 缺少物理尺度时只报告像素数量；如果论文提供校准系数，说明其设备与几何适用条件。
- 版本间数字不同，标明采用哪个版本；表格与文字冲突时保留定位，不擅自修复作者数据。

## 一批页面的完成标准

每篇均有实质讲解，而非只有模板标题。目录的完成数与实际文件一致。上一篇、下一篇与“在对话里问第几篇”的文字随编号正确变化。基础概念可集中在入口篇，但其余页需有返回链接且不丢失本篇所需解释。

保留原图文件与已有用户数据，检查本地发布目录中的相对路径；源目录检查通过，不代表发布目录也能打开原文。静态页面优先无需网络即可阅读正文，原文外链作为查证入口。
